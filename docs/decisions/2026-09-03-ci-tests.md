# Pull Request Test Workflow

Status: accepted implementation convention

Decision date: 2026-09-03

Project Fireworks runs the Python test suite in GitHub Actions for pull requests and pushes to `main`.

The initial workflow currently exercises Python 3.14, installs `requirements-dev.txt`, and runs `python -m pytest -q`.

Using Python 3.14 in this CI job is an execution-environment choice for the current scaffold, not a decision about Fireworks' long-term Python minor-version compatibility or support policy. That policy remains open.

CI is a verification layer, not a substitute for local tests when a local execution environment is available. A failing test workflow blocks treating a change as verified.
